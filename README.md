    USO BÁSICO DE GIT:
    
    0. git clone https://github.com/jcarpio/rc2223_timetable_proyect_A.git
       
    1. git pull 
      (Dentro de la carpeta del repositorio. Comprueba si hay nuevos cambios en el repositorio remoto)
    2. git add .
      (Añadir los ficheros que haya creado al repositorio. Añade también ficheros creados en sub directorios.)
      
    3. git commit -a -m "<mensaje> <fixed> #<num_issue>"
      (crea un punto de recuperación. Es posible volver a un commit previo)
      
    4. git push
      (subir los cambios al repositorio remoto)
          
        
    OBTENER TOKEN EN GIT:
        1. Instale GIT -> https://git-scm.com/downloads
        2. Genere un Token de Acceso Personal(siga los siguientes pasos)
            2.1 Pulse sobre su imagen en la esquina superiro derecha donde le aparecerá un desplegable.
            2.2 Pulse **Settings**.
            2.3 A la izquierda, donde están todas las opciones de Ajustes, bisque y pulse sobre **Developers Settings**.
            2.4 Otra vez en la izquierda, busca y pulsa sobre **Personal Access Token**, debajo aparecerá la opcion **Tokens (classics) ** donde deberemos                     pulsar.
            2.5 En la nueva pestaña, generaremos un **Nuevo Token Clasico**.
            2.6 Asigna un **nombre** a este token, varía su duracion(**expiration**). dale acceso a **Repo, Project, Notifications**.
